# evidence

Screenshots and screen recordings from using Runway. Everything here except this file is ignored by git, so nothing is published or pushed until you choose it.

Name files `YYYYMMDD-HHMM_case_step_what.png`, for example `20261102-2315_living-v1-a1_input.png`.
Steps: input, cost, output, balance, overlay, error, export, ui.

Before publishing any image: hide email and account details, crop out anything showing the address or window view, and strip EXIF and GPS.
